 I added an images section to my portfolio page. First, I created a new folder named images inside my project directory and added three images to it — a profile photo, a project screenshot, and a hobby-related image. Then I used the <img> tag in my HTML to display these images. For each image, I used the src attribute to give the correct relative path like images/profile.jpg, the alt attribute to write meaningful alternative text describing the image for accessibility, and the width and height attributes to set the proper size. I carefully checked that all image paths were correct and verified in the browser that all three images were loading properly without any broken image icons.
